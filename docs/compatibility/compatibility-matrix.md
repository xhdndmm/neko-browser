> 状态取值：Not Started / Planned / In Progress / Partial / Implemented / Tested。
> 最后更新：2026-09（页面内查找 Ctrl+F；此前：页面缩放、`data:` URL、
> `document.domain`；更早：百度首页 in-head noscript、百分比 inset 等）。
